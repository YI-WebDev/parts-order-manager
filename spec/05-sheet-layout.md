# 帳票 `excel-v1`（請求書シート）

利用者の見本帳票（シート「請求書」、印刷範囲 A1:H56）を写した固定の様式です。画面の Excelプレビュー（[F06](features/F06-invoice-editor.md)）・Excel出力（[F08](features/F08-excel-export.md)）・印刷と PDF（[F09](features/F09-print-pdf.md)）は、すべてこの定義から描きます。

定義の場所（同じ値を2つの言語で持つ。どちらかを変えるときは、必ず両方を同時に変える）:

現在、今の TypeScript と Rust の一致を自動で確かめているのは、色・文字の大きさ・既定の揃え（`tests/unit/cell-format.test.ts` が Rust のソースを読んで照合）だけ。差分テスト（`pnpm test:differential`）が比べるのは凍結した旧版の TypeScript で、今の `src/shared` ではない。列幅・行の高さ・配置・記号・納期・はみ出しの一致は、コードを読んで確かめただけで、テストはない（[09-tech-debt.md](09-tech-debt.md) の TD-01）。

| 内容 | TypeScript（画面のプレビュー） | Rust（出力・印刷） |
|---|---|---|
| 配置・既定の書式・記号・納期 | `src/shared/invoice-sheet.ts`・`src/shared/date-text.ts` | `src-tauri/core/src/sheet.rs` |
| 寸法（px）・罫線・はみ出し | `src/shared/sheet-geometry.ts` | `src-tauri/core/src/sheet.rs`（後半） |
| セルの書式・色・文字の大きさ | `src/shared/cell-format.ts` | `src-tauri/core/src/format.rs` |

| ID | 決まり |
|---|---|
| REQ-XLS-101 | 明細は先頭から47行まで帳票に置く。48行目以降は帳票に置かない（プレビューは「帳票に入りません」と示し、出力は止める） |
| REQ-XLS-102 | 帳票に置く文字（帳票上部の欄・明細）は、保存のときに前後の空白（JavaScript の `trim` と同じ全角・半角の空白）を除いた値。画面のプレビューは、保存前の入力も除いた形で描く。出力（Excel・PDF・印刷）も、保存した値の前後の空白を置く前に同じ規則で除く（本体の `sheet::entered`、利用者の決定、2026年10月）ため、2026年10月15日より前に保存し、まだ保存し直していない前後に空白のある値もプレビューと同じ形で出る。納期の判定と一覧の `issueCount` も除いた後の値で行う。文中の空白は残す。セルの表示では改行を除く（折り返しなしの Excel では改行が表示されないため） |
| REQ-XLS-103 | 納期 E4 が実在する日付（`YYYY-MM-DD` または `YYYY/M/D`。区切りは同じ記号、年は1以上）で 1900年3月1日以降なら、日付のシリアル値として置き表示は `m月d日`。それより前の日付と、日付でない文字は文字のまま置く |
| REQ-XLS-104 | 数量は入力した文字のまま文字列として置く（数値に変換しない。数値の書式 `#,##0;[Red]#,##0` は列に付いているが文字列には効かない） |

## チェック記号（規則 `provisional-v1`）

| `deliveryState` | `markOutput` | 記号 | 出力 |
|---|---|---|---|
| `unknown` | `unresolved` | （空欄） | できる（未選択。2026年10月16日から任意の項目） |
| `material_only` | `filled_circle` | ● | できる |
| `slip_only` | `open_circle` | ○ | できる |
| `both` | `both_mark` | ⦿（U+29BF） | できる |
| `both` | `unresolved` | — | 止める（「共に納品」の記号を決める前に保存した明細。⦿ を選び直すまで） |
| 上記以外の組合せ、または規則が `provisional-v1` 以外 | | — | 止める |

⦿ は見本の「白い円に黒い円を重ねた図形」と同じ形の文字。よく似た ◉（U+25C9）は日本語フォントで小さな半角の字形になるため使わない。

## 寸法と書式

| 項目 | 値 |
|---|---|
| 列幅（Excel の文字数単位） | A 7、B 27.33203125、C 24.44140625、D 9.88671875、E 11.109375、F 23.77734375、G 9、H 9 |
| 行の高さ（pt） | 2行目 27、4〜52行目 21.15、それ以外 13.2 |
| フォント | 標準 ＭＳ Ｐゴシック 11pt（列幅の基準）、セル ＭＳ Ｐ明朝 11pt、チェック記号 ＭＳ Ｐ明朝 9pt |
| 既定の配置 | 文字のあるセルはすべて横位置「中央揃え」、縦位置は Excel の既定の下揃え（2026年10月15日、利用者の指示。それまでは見本どおり一部左揃え・字下げ） |
| 罫線 | 見本どおりの細線・二重線（4行目の下・5行目の上下は二重線） |
| 印刷範囲 | A1:G56（見本は H 列までだが、空欄の H 列を除き表を用紙の左右中央に置く） |
| 用紙 | A4 縦、余白 左右0.7インチ・上下0.75インチ、1ページに収める、水平方向に中央 |
| 画面の寸法 | Excel の標準表示（100%・96dpi）と同じ。列幅は標準フォントの数字の幅 8px で Excel と同じ式で換算し、行の高さは pt を px に丸める |
| 印刷・PDF の倍率 | 印刷範囲が A4 縦の余白の内側に収まる倍率（小数第2位で切り捨て。約64%） |

既定のセルの書式（Excel の `cellXfs`）は次の17個で、この順番を変えない（以前に出力したファイルの上書きの確認・バックアップの目録の照合に使う）:
`normal`・`text`・`headFirst`・`head`・`headLabel`・`headDate`・`headEnd`・`titleFirst`・`title`・`titleQuantity`・`titleBox`・`mark`・`lineText`・`lineCenter`・`lineQuantity`・`lineRemarks`・`lineEnd`。

## 文字のはみ出し（Excel に合わせた表示）

| 横位置 | はみ出し方 |
|---|---|
| 左揃え | 右に続く空欄のセルへはみ出す |
| 右揃え | 左に続く空欄のセルへはみ出す |
| 中央揃え | セルの中央に置いたまま、左右に続く空欄へ同じ幅だけ（短い側の空欄の幅まで）はみ出す。片側の隣が埋まっていればはみ出さない（Excel では空いている側へだけはみ出すため、ここは Excel と違う） |

はみ出した範囲の枠線（グリッド線）は描かない。セルに入りきらない文字は途中で切れる。
