# 非機能要件

## セキュリティ・プライバシー（SEC）

| ID | 要件 | 実装・確認 |
|---|---|---|
| NFR-SEC-001 | 外部と通信しない（ログイン・同期・自動更新・送信なし）。配布版は依存の取得なしで動く | CSP の `connect-src`、`tests/e2e/release-offline.spec.ts` |
| NFR-SEC-002 | 画面から呼べるのは `ipc` コマンドだけ。Tauri のほかの機能（ファイル・ウィンドウ操作など）は許可しない | `capabilities/main.json`、`build.rs` |
| NFR-SEC-003 | 画面は最初に読み込んだアプリのページ以外へ移動しない。新しいウィンドウ・ダウンロード・権限の要求は拒否する | `lib.rs` |
| NFR-SEC-004 | 業務処理は、要求の送り主がアプリのページかを確かめ、入力をすべて検査する（画面の検査に頼らない） | `api.rs` `trusted`、`validate.rs` |
| NFR-SEC-005 | 画面に任意のファイルの場所を指定させない。ファイルは OS のダイアログか、WebView2 から本体が直接受け取ったドロップだけ | `host.rs`、`tauri-api.ts` |
| NFR-SEC-006 | 材料Excelは、マクロ・埋め込み・外部リンク・DTD を含むものを取り込まない。ZIP・XML は上限（[06-limits.md](06-limits.md)）の内側だけを読む | `imports/workbook.rs`・`zip.rs`・`xml.rs`、`core/tests/security.rs` |
| NFR-SEC-007 | 出力先は、ローカルドライブの絶対パス（Windows は `C:\` の形）で、保存場所・アプリのフォルダーの外。UNC は拒否する。既存ファイルの上書きは、このアプリの出力と確かめられたものだけ | `exports/files.rs` |
| NFR-SEC-008 | 印刷プレビューはスクリプトを無効にし、ハッシュを指定した CSP でスタイルを固定する | `preview.rs`・`printing.rs` |
| NFR-SEC-009 | DB・バックアップ・出力した帳票は暗号化しない。その旨を画面（設定）と README に書く | `BackupPanel.tsx` |
| NFR-SEC-010 | E2E 用の操作口（ダイアログの代役・障害の注入）は配布用のビルドに入れない | `Cargo.toml` の `e2e` 機能、`build.rs` |

## 信頼性・データ保全（REL）

| ID | 要件 | 実装・確認 |
|---|---|---|
| NFR-REL-001 | 書き込みはトランザクションで行い、途中で失敗したら何も変えない（請求書の保存・削除、材料の削除、取込の確定、更新取込の確定、移行） | `db.rs` `transaction` |
| NFR-REL-002 | 応答が届かなかった要求を同じ内容で送り直しても、二重に反映しない（請求書の保存は要求番号と内容、材料の作成は作成要求 ID、削除は「見つからない ID は削除済み」） | `documents.rs`・`reimport.rs`・`materials.rs` |
| NFR-REL-003 | 保存の結果が分からないとき（応答なし・応答の不一致）は、入力を保持し、同じ要求で再確認できるようにする。結果が分かるまで請求書を閉じない・切り替えない | `editor-store.ts` |
| NFR-REL-004 | ファイルの新規保存は、同じフォルダーの一時ファイルに書いてから、同名のファイルがない場合に限って確定する（Windows は置換なしの移動、ほかはハードリンク）。上書きは、選んだ後にファイルが変わっていないことを確かめてから置き換える。消せなかった一時ファイルは名前を利用者に示す | `exports/files.rs` |
| NFR-REL-005 | 出力の確定の直前に、保存版と出力の内容が準備したときと同じかを確かめる | `api.rs` `export_steps`・`verify_print` |
| NFR-REL-006 | 復元は切替記録を使い、途中で止まっても次の起動で「確定」か「元の DB に戻す」のどちらかにする。復元前の DB は残す | `backups.rs` |
| NFR-REL-007 | DB を移行する前に複製を残し、検証できなければ移行しない | `db.rs` |
| NFR-REL-008 | 想定外の内部エラーでも黙って消えない（エラーを表示してから終わる）。画面の描画のエラーでは、保存済みの内容は保持されていると示し、終了できる画面を出す | `lib.rs`、`ErrorBoundary.tsx` |

## 日本語入力（IME）

| ID | 要件 |
|---|---|
| NFR-IME-001 | すべての検索欄（明細最終行・材料検索パレット・材料台帳・カテゴリ候補・請求書一覧）は、変換中も確定を待たずに入力中の文字で検索する（2026年10月14日、利用者の指示）。送る検索語は先頭の256文字まで |
| NFR-IME-002 | 請求書の編集画面の欄で変換中は、自動保存・保存・出力・画面の移動・明細の追加を止め、「変換確定を待っています」と示す |
| NFR-IME-003 | 変換中の欄からフォーカスが外れたら、変換は終わったとみなす（compositionend が届かない場合に備える）。ウィンドウの切り替えだけでは解除しない |
| NFR-IME-004 | 変換中の Enter・矢印キー・ショートカット（Ctrl+F・Ctrl+S・Ctrl+N・Ctrl+B など）は IME に任せ、アプリの操作にしない |
| NFR-IME-005 | 編集画面の欄で変換中にウィンドウを閉じようとしたら、閉じずに「日本語の変換を確定してから、もう一度閉じてください。」と示す。編集画面の外の変換中（検索語など）はそのまま終了確認へ進む |

実機（WebView2＋MS-IME）での確認手順は `audit/2026-10-14-app-audit.md` の 7.3 節。

## 操作性・アクセシビリティ（UX）

| ID | 要件 |
|---|---|
| NFR-UX-001 | 主な操作はキーボードでできる（ショートカットは [F11](features/F11-app-shell.md)、明細の並べ替えは Alt+↑↓、チェックは矢印キーと Space・Enter） |
| NFR-UX-002 | 状態・エラーは `role="status"`・`role="alert"` で読み上げられるようにする。ボタンには内容が分かる名前（`aria-label`）を付ける |
| NFR-UX-003 | 処理中は、ほかの操作（タブの移動・材料検索パレット・ショートカット）を止め、処理中であることを示す |
| NFR-UX-004 | 取り消せない操作（請求書・材料の削除、復元）は確認してから行い、既定のフォーカスは「戻る」にする |
| NFR-UX-005 | 一覧で削除した後は、消えた位置に来た項目へフォーカスを移す（フォーカスが失われているときだけ） |
| NFR-UX-006 | 0件のときは、絞り込みの有無に応じて次にすべきことを示す（例: 材料が1件もないときは登録の仕方を示す） |

## 対応環境・性能（ENV）

| ID | 要件 |
|---|---|
| NFR-ENV-001 | Windows 11 x64 で、管理者権限なしでインストール・起動できる（現在のユーザー用のインストール）。Windows 10 は未検証 |
| NFR-ENV-002 | 画面の表示倍率・フォントの違いで、プレビューの文字のはみ出し方がわずかに変わることは許容する（プレビューは100%・96dpi 相当で描く） |
| NFR-ENV-003 | 最小化している間は WebView2 のメモリ使用を抑える（MemoryUsageTargetLevel）。自動保存・終了確認は止めない |
| NFR-ENV-004 | 扱える量は [06-limits.md](06-limits.md) の上限まで。上限を超えたら、処理を止めて理由を示す（途中まで反映しない） |
| NFR-ENV-005 | exFAT・FAT32 の保存先（USB メモリなど）にも新規保存できる（実媒体での確認は未実施） |
