# F09 印刷プレビュー・PDF保存・印刷

保存版の請求書を、画面の Excelプレビューと同じ形で A4 縦1ページの印刷プレビューに出し、PDF に保存するか、プリンターで印刷する。

- 画面: 編集画面の「印刷プレビュー・PDF」（`useInvoiceWorkspace.ts` `printPreview`）、印刷プレビューのウィンドウ（本体が作る HTML）
- IPC: `documents:print-preview`
- 実装: `src-tauri/core/src/api.rs`（`print_preview`・`PrintSession`・`save_pdf`）、`printing.rs`（HTML・CSS・CSP）、`src-tauri/src/preview.rs`（ウィンドウ）、`win.rs`（Windows の PDF 化・印刷）、`gtk_print.rs`（Linux、開発用）

## 要件

| ID | 要件 |
|---|---|
| REQ-PRT-001 | 開く前の手順（変換中は止める・未保存の変更を保存し終える・保存版が1以上）は Excel出力と同じ（[F08](F08-excel-export.md) の流れ1〜2）。保存できなければ「保存を完了できないため印刷プレビューを開いていません。保存を再試行してください。」 |
| REQ-PRT-002 | 止める理由は Excel出力と同じ（REQ-XLS-002）。止めたら `blocked` を返し、画面は出力前の確認の一覧に「確認が必要なため印刷プレビューを止めました」として示す |
| REQ-PRT-003 | Excel と同じ文字・容量の制約（REQ-XLS-004）を、ウィンドウを作る前に確かめる |
| REQ-PRT-004 | 印刷プレビューは同時に1つだけ（「開いている印刷プレビューを閉じてください。」）。開いている間はメインウィンドウを操作できず、バックアップ・復元も始められない |
| REQ-PRT-005 | 印刷プレビューのウィンドウは、スクリプトを無効にした専用のプロファイルで、保存版の帳票の HTML だけを表示する。ページ内のリンク（PDF保存・印刷・閉じる）は移動させずに操作として受け取る |
| REQ-PRT-006 | 帳票は印刷範囲（A〜G 列）を、Excel と同じ余白（左右0.7インチ・上下0.75インチ）の内側の A4 縦1ページに収まる倍率（約64%）で、左右中央に置く。罫線・はみ出し・書式は画面のプレビューと同じ |
| REQ-PRT-007 | PDF保存: 「PDFを作成しています。…」を出し、保存版が変わっていないことを確かめてから PDF にし、もう一度確かめてから保存のダイアログ（既定は「ドキュメント」の `請求書.pdf`）を出す |
| REQ-PRT-008 | PDF は `%PDF-` で始まる8,000,000バイト以下のものだけ保存する。保存するファイルの末尾に、このアプリの PDF である印 `%parts-order-manager:pdf-v1` を付ける |
| REQ-PRT-009 | 既存の PDF への上書きは、そのファイルがこのアプリの PDF（`%PDF-` で始まり印で終わる）のときだけ、確認（「戻る」「上書きする」）してから行う。それ以外は「このアプリの形式以外のPDFは上書きできません。別名で保存してください。」 |
| REQ-PRT-010 | 出力先の検査・一時ファイル経由の確定・確定の直前の保存版の確認は Excel出力と同じ（REQ-XLS-005・007・008。拡張子は `.pdf`） |
| REQ-PRT-011 | 印刷: Windows 標準の印刷ダイアログでプリンター・部数・両面などを選び、WebView2 の印刷機能で印刷する。結果は「印刷処理を受け付けました。紙への印刷完了はプリンターで確認してください。」「印刷を取り消しました。」「印刷処理を確認できませんでした。…」のどれかを、プレビューに表示する |
| REQ-PRT-012 | PDF保存・印刷の処理中は、プレビューのウィンドウを閉じさせず、ほかのリンクも受け付けない。失敗したら「出力を完了できませんでした。最新の保存版・出力条件・プリンターを確認してください。」 |
| REQ-PRT-013 | プレビューを閉じたら `{status: 'closed'}` を返す。開けなかったら「印刷プレビューを開けませんでした。保存版・文字量・出力条件を確認してください。」 |
| REQ-PRT-014 | PDF保存・印刷は、請求書一覧の「出力済み」の記録に含めない（記録するのは Excel出力だけ） |

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-PRT-001 | 明細46行の請求書 | 印刷プレビューから PDF保存 | 1ページの PDF ができ、末尾にこのアプリの印がある |
| AC-PRT-002 | このアプリで保存した PDF | 同じ名前で PDF保存し「上書きする」 | 置き換わる |
| AC-PRT-003 | 別のアプリの PDF | 同じ名前で PDF保存 | 上書きしない |
| AC-PRT-004 | 記号未確定の明細 | 印刷プレビュー | 開かず、出力前の確認の一覧に「確認が必要なため印刷プレビューを止めました」と該当の明細が出る。編集画面のスクロール位置とフォーカスは変わらない |
| AC-PRT-005（想定外の操作） | 印刷プレビューを開いている | もう一度「印刷プレビュー・PDF」、バックアップ | どちらも始まらない |

## 未確定・既知の問題

- 実際のプリンターでの印刷は、自動テストでは結果を差し替えている（`audit/` の O-03: 印刷の余白で2ページに分かれるおそれ）。
- O-09: PDF の一時ファイルの案内が Windows では誤り。
- Electron 版と、印刷ダイアログの見た目・選べる項目が少し違う。
