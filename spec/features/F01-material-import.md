# F01 材料の初回取込

材料Excelを解析し、原記録として保存してから、利用者が確認して材料に登録する。元の Excel は変更しない。

- 画面: 「材料」タブ →「Excelから取込」→「新しいExcelを初回取込」（`ImportWizard.tsx`）
- IPC: `imports:choose`・`imports:choose-from-path`・`imports:review`・`imports:apply`・`imports:cancel`・`imports:resume`・`imports:list`
- 実装: `src-tauri/core/src/imports/`（`source.rs`・`workbook.rs`・`cells.rs`・`repository.rs`）

## 材料Excelの形

```text
     A    B              C         D     E    F    G      H    I              J         K     L    M
1   品名 形式又はタイプ メーカー 数量 備考 単価 (補足) 品名 形式又はタイプ メーカー 数量 備考 単価
2〜  左ブロックの材料                                    右ブロックの材料
```

- 見出しの比較は、NFKC 正規化して空白を除いた文字で行う（半角カナ・全角英数・空白の違いは同じとみなす）。
- シート名が「請求書」で B5〜F5 が請求書の見出しのシートは、帳票として読み飛ばす。

## 要件

| ID | 要件 |
|---|---|
| REQ-IMP-001 | 取り込めるのは拡張子 `.xlsx` の 16 MiB 以下のファイル。ファイル選択のダイアログか、ドロップ（1つだけ）で選ぶ。`.xls`・CSV・`.ods` は取り込まない |
| REQ-IMP-002 | 一時フォルダーに複製してから解析し、解析の前後で元のファイルのハッシュが変わっていたら「解析中に元のExcelが変更されました。…」（`CHANGED`）にする |
| REQ-IMP-003 | マクロ・埋め込みファイル・外部参照のシート・DTD を含むファイル、ZIP・XML の上限（[06-limits.md](../06-limits.md)）を超えるファイルは取り込まない |
| REQ-IMP-004 | 帳票として読み飛ばすシート以外は、1行目の A〜F と H〜M が材料表の見出しと一致しなければ「材料表の左右の見出しを確認できません（シート順N）。」（`FORMAT`）にする。材料表が1つもなければ「材料表がありません。」 |
| REQ-IMP-005 | 材料表の各行（1行目から、値のある最後の行まで）を、左右のブロックごとに1項目として分類する。ブロックのセルがすべて空なら項目にせず「空行ブロック」として数える |
| REQ-IMP-006 | 分類: 見出しと同じ内容で表示を確認できる行は「列見出し」、表示を確認でき品名・型式がある行は「材料候補」、それ以外は「要確認」 |
| REQ-IMP-007 | 次のどれかに当たる行は「表示を確認できない」とし要確認にする: 非表示のシート・結合セル・非表示の列があるシートの行、非表示の行のセル、数式のセル、表示形式を再現できない数値・文字列のセル |
| REQ-IMP-008 | G 列と、M 列より右の列の値のあるセルは、1つずつ「補足セル」にする（材料にしない） |
| REQ-IMP-009 | 材料の値は、セルの表示文字列から前後の空白を除いたもの。原記録（原セル）は元の値・表示文字列・表示形式・セルの種類を変えずに保存する |
| REQ-IMP-010 | 同じ内容（SHA-256 が同じ）の Excel を選んだら、新しい記録を作らずに以前の記録を開く |
| REQ-IMP-011 | 確定済みの初回取込がある状態で内容の違う Excel を選んだら「確定済みのExcelと内容が異なります。変更したExcelは、取込の種類で「変更したExcelで更新」を選んで取り込んでください。」（`CONFLICT`）にする。確認中の取込があれば「確認中の取込があります。…」 |
| REQ-IMP-012 | 解析した結果は、確認中（`preview`）の取込記録と原記録として保存する。この時点では材料を作らない |
| REQ-IMP-013 | 確認の画面では、材料候補を既定で選ぶ。要確認・列見出しの行も、品名があれば選べる。補足セルと品名のない行は選べない（理由を表示する） |
| REQ-IMP-014 | 確定（`imports:apply`）では、選んだ行ごとに材料を作り、すべての項目に判断履歴を残す（選んだ行は `new`、列見出しで選ばなかった行は `non_material`、ほかは `hold`） |
| REQ-IMP-015 | カテゴリはシートごとに1つ。シート名を名前、シートの順番を並び順にして作る。同じ取込元の同じシート順のカテゴリが既にあれば、それを使う（既存の同名カテゴリへは自動で統合しない） |
| REQ-IMP-016 | 確定は1つのトランザクションで行う。DB の失敗で確定できなければ材料を1件も作らず、記録を「保存失敗」（`failed`）にして「保存に失敗しました。材料への反映は取り消しました。履歴から再確認できます。」（`DB`）を返す |
| REQ-IMP-017 | 確定・取消・再確認は、この起動中に `imports:review`（または選択）で開いた記録に限る。開いていなければ「履歴から取込内容を開いてください。」 |
| REQ-IMP-018 | 確認中の記録は取り消せる（`cancelled`）。原記録は残る |
| REQ-IMP-019 | 確定済み・取消・保存失敗の記録から、まだ材料にしていない選べる行を「再確認」できる。新しい確認中の記録（`kind = 'resolution'`）を作る。再確認できないときは、その理由（`resumeBlocked`）を返し、画面はボタンを出さずに理由を示す |
| REQ-IMP-020 | 再確認できない条件: 更新取込を始めている／別の取込（取込元またはファイルが違う）が確定済み／未反映の選べる行がない／別の取込を確認中 |
| REQ-IMP-021 | 同時に選べる Excel は1つだけ。解析中にもう一度選ぶと「別のExcelを確認中です。」（`CONFLICT`） |

## 取込記録の状態

| 状態 | 意味 | 次の状態へ | 操作 |
|---|---|---|---|
| （なし） | | 確認中 | ファイルを選ぶ（同じファイルなら既存の記録を開く） |
| 確認中 `preview` | 原記録を保存し、選択を待つ | 確定済み | 確定（選んだ行を材料にする） |
| | | 取消 | 取り消す |
| | | 保存失敗 | 確定の途中で DB が失敗した |
| 確定済み `applied` | 材料を作った。もう一度は確定しない | 確認中（新しい記録） | 再確認（未反映の行がある場合） |
| 取消 `cancelled` | 材料を作っていない | 確認中（新しい記録） | 最初から確認し直す |
| 保存失敗 `failed` | 材料を作っていない | 確認中（新しい記録） | 再確認 |

画面の手順（ウィザード）: 1. 種類 → 2. ファイル → 3. 内容を確認 → 4. 確定。解析した後はファイルを選び直せない（「この取込を取り消す」で取り消してから選び直す）。確認中のまま画面を離れても記録は残り、取込履歴から再開できる。

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-IMP-001 | 左右のブロックに材料が並ぶ正しい材料Excel | 初回取込で選ぶ | 確認中の記録ができ、品名・型式のある行が材料候補として選ばれている。材料はまだない |
| AC-IMP-002 | AC-IMP-001 の確認画面 | 確定する | 選んだ行の数だけ材料ができ、シート名のカテゴリに入る。記録は確定済みになる |
| AC-IMP-003 | 型式が空の行 | 確認画面で見る | 要確認になり既定では選ばれないが、チェックすれば確定で材料にできる |
| AC-IMP-004 | 品名が空の行・G 列のセル | 確認画面で見る | チェックできず、理由（品名がない・補足セル）が出る |
| AC-IMP-005 | 確定済みの初回取込がある | 内容の違う Excel を初回取込で選ぶ | `CONFLICT` で「変更したExcelで更新」へ案内される |
| AC-IMP-006 | 確定済みの初回取込と同じファイル | もう一度選ぶ | 新しい記録を作らず、確定済みの記録が開く |
| AC-IMP-007 | 確定の途中で DB が失敗する | 確定する | 材料は1件もできず、記録は保存失敗になり、再確認できる |
| AC-IMP-008 | 一部を選ばずに確定した記録 | 「未反映の候補を再確認」を押す | 未反映の行だけの確認中の記録が開く |
| AC-IMP-009 | 更新取込を始めた取込元の、古い初回取込の記録 | 開く | 再確認のボタンは出ず、「更新取込が開始されています。…」が出る |
| AC-IMP-010 | マクロ付きのブック・`.xls` | 選ぶ | 取り込まず、理由が出る |
| AC-IMP-011（想定外の操作） | 確認画面を開いていない記録の ID | `imports:apply` を直接呼ぶ | 「履歴から取込内容を開いてください。」で拒否される |

## 未確定・既知の問題

`audit/2026-10-14-app-audit.md` の未対応の指摘のうち、この機能に関わるもの（状況は監査文書を正とする）:

- I-03: 材料の列と無関係な非表示列・結合セル1つで、シートの全行が要確認になる。
- I-04: 3,300行（6,600材料）の材料表は、初回取込はできても更新取込が上限で止まる。
- I-05: 名前がちょうど「請求書」でない、材料表でないシートが1枚でもあると、ブック全体を取り込めない（REQ-IMP-004 のとおりの動きだが、業務上の扱いは未確定）。
- I-06・I-07・I-08・I-11・I-12・I-13・I-14・I-15: 数値の表示、共有数式、`_xHHHH_` の復号、補足セルの位置表示、件数の表示、再確認での列見出しの行、エラーの文言、解析の負荷。
- 画面の「採用できるか」の判定（`ImportWizard.tsx` `adoptable`）は本体（`imports/repository.rs` `adoptable`）の写し（[09-tech-debt.md](../09-tech-debt.md) の TD-23）。
