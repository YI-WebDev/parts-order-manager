# F04 材料台帳

材料の一覧・手動での追加と編集・無効化・削除、取込履歴の表示を行う。

- 画面: 「材料」タブ（`MaterialManager.tsx` の `Ledger`・`MaterialDrawer`・`ImportHistory`）
- IPC: `materials:search`・`materials:categories`（一覧）、`master:get`・`master:save`・`master:delete`、`imports:list`・`reimport:list`（取込履歴）
- 実装: `src-tauri/core/src/reimport.rs`（`MasterService`）、`materials.rs`

## 一覧（材料台帳）

| ID | 要件 |
|---|---|
| REQ-MAT-001 | 検索の規則は [F03](F03-material-search.md) と同じ。キーワード（品名・型式・メーカー・備考）・カテゴリ・「無効も表示」で絞り、25件ずつ表示する |
| REQ-MAT-002 | カテゴリの一覧は「すべて」（材料の総数）と各カテゴリ（件数）を並べ、100件を超えるときは検索欄とページ送りを出す。今のページ・検索結果にない選択中のカテゴリは先頭に「選択中」として残す |
| REQ-MAT-003 | 列は品名・型式・メーカー・数量・備考・状態（有効／無効）と、編集・削除のボタン。無効の材料は見た目で区別する |
| REQ-MAT-004 | 選択は表示中のページ・検索条件の中だけで持ち、検索語・カテゴリ・「無効も表示」・ページを変えると解除する。「このページをすべて選択」と「選択した N件を削除」を出す |
| REQ-MAT-005 | 材料の編集・削除の処理中は、検索の欄も含めて操作を止める |

## 手動での追加・編集（ドロワー）

| ID | 要件 |
|---|---|
| REQ-MAT-101 | 「手動で追加」で新規、行の「編集」で既存の材料を開く。開くとき本体から材料・カテゴリ候補（先頭100件）・新規なら作成要求 ID を受け取る |
| REQ-MAT-102 | カテゴリは既存から選ぶか、「新しいカテゴリ」で名前（1,000文字まで）を入力する。新規の既定のカテゴリは候補の先頭 |
| REQ-MAT-103 | 6項目（品名・型式・メーカー・数量・備考・単価）は各10,000文字まで。保存時に前後の空白を除く。品名が空（空白だけを含む）なら、画面では保存ボタンを押せず、本体（`master:save`）も `VALIDATION`「品名を入力してください。」で拒否する（取込の採用と同じく品名は必須） |
| REQ-MAT-104 | 「有効」を外すと無効になり、材料検索パレット・明細への追加の対象から外れる（作成済みの請求書は変わらない） |
| REQ-MAT-105 | 既存の材料の保存は版で確かめ、ほかで変わっていたら「材料は変更されています。再読込してください。」 |
| REQ-MAT-106 | 新規の保存は作成要求 ID が必要。同じ ID・同じ内容の再送には、最初に作った材料をそのまま返す（二重に作らない）。同じ ID で内容が違えば「同じ作成要求の内容が異なります。…」。発行していない・古い（直近128件より前）ID は「新規作成要求が失効しています。…」 |
| REQ-MAT-107 | 新規の保存の結果が分からないとき（応答なし）は、入力を固定し「同じ内容で再試行」できるようにする。閉じても保存の取り消しにはならないことを示す |
| REQ-MAT-108 | 編集中は、元の値と違う項目に「変更あり」を示す。Excel 由来の材料は「前回確認済み取込値と現在値を比較」で、取込値との違いを項目ごとに示す（空白・改行を記号で見る表示を切り替えられる） |
| REQ-MAT-109 | ドロワーを開いている間は、画面の移動・終了などのほかの操作を止める。Ctrl+S で保存する（変換中は保存しない）。Esc・背景のクリックで閉じる（入力は確認なしで捨てる） |
| REQ-MAT-110 | 保存しても、作成済みの請求書の明細は変わらない |

## 削除

| ID | 要件 |
|---|---|
| REQ-MAT-201 | 1件ずつ（行のごみ箱）、または選んだものをまとめて（1〜100件）削除する。確認の画面に、品名・型式・メーカー・カテゴリ（無効ならその旨）を並べ、既定のフォーカスは「戻る」 |
| REQ-MAT-202 | 削除は取り消せない（戻すにはバックアップから復元）。削除した材料は、材料台帳・材料検索・カテゴリの件数・明細への追加・更新取込の確認・バックアップの件数から外れる。作成済みの請求書の明細と取込履歴は変わらない |
| REQ-MAT-203 | すべて削除するか、何も削除しない。削除済み・見つからない ID は削除済みとして扱う |
| REQ-MAT-204 | 削除した行はすぐに一覧から外し、表示したまま読み直してから、消えた位置に来た行のチェックへフォーカスを移す（行がなければキーワード欄。フォーカスが失われているときだけ）。ページが空になったら、後ろのページがあれば読み直し、なければ前のページへ戻る |
| REQ-MAT-205 | 結果が分からないとき（応答なし）は「削除の結果を確認できませんでした。一覧を読み直したので、材料が残っているかを確認してください。」を出し、一覧を読み直す |
| REQ-MAT-206 | 削除した材料を、材料検索パレットの選択から外す |

## 取込履歴

| ID | 要件 |
|---|---|
| REQ-MAT-301 | 初回取込と更新取込の記録を合わせて、作成日時の新しい順に並べる（それぞれ100件まで）。列はファイル・種類・状態（確認中／確定済み／取消／保存失敗）・「反映 N件・保留 M件」・日時 |
| REQ-MAT-302 | 「開く」で取込の画面（[F01](F01-material-import.md)・[F02](F02-material-reimport.md)）の確認の手順から開く |

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-MAT-001 | — | 手動で追加し、品名「 ボルト 」で保存 | 品名「ボルト」で登録され、一覧に出る |
| AC-MAT-002 | 新規の保存の応答が届かない | 「同じ内容で再試行」 | 材料は1件だけできる |
| AC-MAT-003 | 材料を編集画面で開いた後、別の経路で同じ材料が変わった | 保存する | 「材料は変更されています。再読込してください。」で保存されない |
| AC-MAT-004 | 材料を明細に入れた請求書がある | その材料を削除する | 台帳・検索から消え、請求書を開くと明細は元の値のまま。保存もできる |
| AC-MAT-005 | 2ページ目の最後の1件 | 削除する | 1ページ目に戻り、フォーカスはそのページの最後の行のチェックへ移る |
| AC-MAT-006（想定外の操作） | ドロワーを開いている | Ctrl+F・タブの移動 | 何も起きない |

## 未確定・既知の問題
