# F02 変更したExcelでの更新取込

初回取込を確定した取込元の、変更した Excel を読み、既存の材料との対応と差分を利用者が確認してから反映する。自動では何も反映しない（既定はすべて保留）。手動で作った材料と、作成済みの請求書は変わらない。

- 画面: 「材料」タブ →「Excelから取込」→「変更したExcelで更新」（`ImportWizard.tsx` の `ReReview`）
- IPC: `reimport:series`・`reimport:choose`・`reimport:choose-from-path`・`reimport:review`・`reimport:apply`・`reimport:cancel`・`reimport:resume`・`reimport:list`
- 実装: `src-tauri/core/src/reimport.rs`（解析は [F01](F01-material-import.md) と同じ `imports/workbook.rs`）

## 用語

| 用語 | 意味 |
|---|---|
| 取込元の先頭 | 取込元の確定済みの初回取込から、確定済みの更新取込をたどった最後の記録（`head`）。分岐していたら更新取込できない |
| 取込元の材料 | 最後に反映した原記録（`last_source_item_id`）がその取込元にある材料（削除した材料は除く） |
| 前回の取込値 | 材料に最後に反映した原記録の値（「前回確認済み取込値」） |

## 要件

| ID | 要件 |
|---|---|
| REQ-RIM-001 | 更新できる取込元は、初回取込（または再確認）を確定した取込元。一覧には取込元の最初のファイル名を出す（100件まで） |
| REQ-RIM-002 | ファイルの条件・解析は初回取込と同じ（REQ-IMP-001〜009） |
| REQ-RIM-003 | 同じ取込元で同じ内容のファイルを選んだら、新しい記録を作らずにその記録を開く。ほかの取込（初回・更新）を確認中なら「別の取込を確認中です。先に確定または取消してください。」 |
| REQ-RIM-004 | 新しい Excel の各行を、取込元の材料と比べて分類する: 材料候補でない行は「保留・表示要確認」（`held`）、前回の取込値が6項目すべて一致する材料が1つなら「同内容」（`same`）、前回の取込値の品名・メーカーが一致する材料が1つなら「変更あり」（`changed`）、2つ以上なら「複数候補・要判断」（`ambiguous`）、なければ「対応なし」（`unmatched`）。候補の材料は20件まで返す |
| REQ-RIM-005 | 取込元の有効な材料のうち、新しい Excel のどの行の候補にもならないものを「Excelに見当たらない」（`missingIds`）として返す。再確認のときは、元のブック全体（反映済みの行を含む）と比べる |
| REQ-RIM-006 | 確定（`reimport:apply`）では、確認中の全行について「保留」「新規材料として追加」「差分を反映（材料と反映する項目）」のどれかを受け取る。`confirmed: true` が必要 |
| REQ-RIM-007 | 「新規」と「反映」は、品名のある、列見出しでない行だけ選べる。補足セル・品名のない行・列見出しは保留だけ（違反は「要確認の原記録は保留してください。」） |
| REQ-RIM-008 | 「反映」では、選んだ項目だけを新しい Excel の値にし、ほかの項目はアプリの値を保つ。カテゴリ・有効／無効は変えない。1つの材料に対応付けられる行は、同じ確定の中でも、同じ元ブックの別の行との間でも1つだけ |
| REQ-RIM-009 | 「新規」の材料は、同じシート名の取込元の材料と同じカテゴリに入れる。そのシートの材料をすべて削除していれば、削除した材料のカテゴリに入れる。どちらもなければシート名のカテゴリを作る |
| REQ-RIM-010 | 「Excelに見当たらない」材料は、既定で保持する。利用者が「無効にする」を選んだ材料だけ無効にする（削除はしない）。無効にできるのは取込元の材料だけ |
| REQ-RIM-011 | 確定では、すべての原記録と、対応付けなかった取込元の材料に判断履歴を残す（`new`・`apply`・`hold`・`non_material`・`keep`）。反映した材料の「前回の取込値」はこの原記録になる |
| REQ-RIM-012 | 確認を始めた後に、取込元の先頭が変わった・取込元の材料（版・値・カテゴリ・有効・削除）が変わった場合は「古い確認」（`stale: true`）とし、確定させない（「材料または取込履歴が変更されています。再確認してから適用してください。」）。画面は「未反映分を再確認」を出す |
| REQ-RIM-013 | 確定は1つのトランザクションで行い、確定済みの記録をもう一度確定しても何もしない（同じ確認結果を返す） |
| REQ-RIM-014 | 再確認（`reimport:resume`）は、取込元の先頭の記録か、先頭の直後の記録からだけできる（後続の Excel が確定済みなら「後続のExcelが確定済みです。…」）。未反映の行（列見出しを除く）だけで新しい確認中の記録を作る。古い確認中の記録は取り消しにする |
| REQ-RIM-015 | 取消・確定・再確認は、この起動中に開いた記録に限る（「履歴から今回の取込を開いてください。」）。初回取込の記録は更新取込のチャネルで取り消せない |
| REQ-RIM-016 | 更新取込の確認中（`preview`）は、画面の移動・終了などのほかの操作を止める（画面全体を処理中にする） |

## 画面の決まり

| ID | 決まり |
|---|---|
| REQ-RIM-101 | 一覧は既定で「確認が必要」だけを出す。確認が必要な行: 判断を保留以外にした行、または、反映済みでも補足セルでもなく、候補が1つでその前回の取込値と6項目すべて一致する、のどちらでもない行。「Excelに見当たらない」材料も含める |
| REQ-RIM-102 | 「Excelに見当たらない」材料は、前回あった位置（同名シートの行番号）に並べる |
| REQ-RIM-103 | 「差分を反映」を選んだとき、既定で反映する項目は、アプリの値が前回の取込値のまま、または新しい値と同じ項目。両方が変わった項目（競合）は既定で選ばない |
| REQ-RIM-104 | 1ページ10件。確定した判断履歴は25件ずつ |

## 取込記録の状態

| 状態 | 次の状態 | 操作・条件 |
|---|---|---|
| 確認中 | 確定済み | 確定（古い確認でないこと） |
| 確認中 | 取消 | 取り消す、または再確認で新しい記録を作った |
| 確認中（古い確認） | 確認中（新しい記録） | 再確認 |
| 確定済み・取消 | 確認中（新しい記録） | 再確認（未反映の行があり、後続の Excel が確定していない） |

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-RIM-001 | 初回取込を確定した取込元 | 1行の型式だけ変えた Excel で更新取込する | その行は「変更あり」、ほかは「同内容」。既定ではすべて保留で、確定しても材料は変わらない |
| AC-RIM-002 | AC-RIM-001 | 変更ありの行を「差分を反映」にして型式だけ選び確定する | その材料の型式だけが新しい値になり、ほかの項目・カテゴリは変わらない |
| AC-RIM-003 | 材料の型式をアプリで編集し、Excel でも型式を変えた | 確認画面で「差分を反映」を選ぶ | 型式は「競合」と表示され、既定で選ばれていない |
| AC-RIM-004 | Excel から1行を消した | 更新取込する | その材料が「Excelに見当たらない」として前回の位置に出る。既定は保持、「無効にする」で無効になる |
| AC-RIM-005 | 確認中に、対象の材料をほかの画面で編集・削除した | 確定する | 確定できず、「未反映分を再確認」が出る |
| AC-RIM-006 | 同じ材料を2行で「差分を反映」にする | 確定する | 拒否される |
| AC-RIM-007 | シートの材料をすべて削除した取込元 | その行を「新規材料として追加」で確定する | 削除した材料と同じカテゴリに入る（同名のカテゴリが増えない） |
| AC-RIM-008（想定外の操作） | 確認中の更新取込 | タブの移動・材料検索パレットを開こうとする | 操作できない |

## 未確定・既知の問題

- 新しい材料のカテゴリを、初回取込はシートの順番、更新取込はシート名で探すため、シートを並べ替え・改名すると2つの経路で違うカテゴリになる（[09-tech-debt.md](../09-tech-debt.md) の TD-41。どちらにそろえるかは未決定）。

`audit/2026-10-14-app-audit.md` の未対応の指摘: I-01（無効にした材料の行が戻っても案内されない）、I-02（確認中にウィンドウの×が無視される）、I-04（3,300行で上限）、I-09（新規追加のカテゴリが不定になる場合）、I-10（同じ材料を2行に対応付けたときのエラー表示）、I-16（初回取込の再確認中の更新取込）、I-17（「既存材料を探す」が全角・半角を区別する）。
