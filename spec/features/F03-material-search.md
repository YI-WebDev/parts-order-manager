# F03 材料検索

材料を部分一致で探す。3つの場所で使う: 材料検索パレット（複数を選んで明細へまとめて追加）、明細最終行の検索欄（1件ずつ追加）、材料台帳（[F04](F04-material-ledger.md)）。カテゴリが多くても使えるよう、カテゴリ候補は100件ずつ検索・ページ送りして選ぶ。

- 画面: `MaterialPalette.tsx`、`InvoicePanel.tsx` の `AddLineRow`、`useMaterialSearch.ts`・`useCategoryPage.ts`・`CategoryPager.tsx`
- IPC: `materials:search`・`materials:categories`、追加は `documents:add-line`
- 実装: `src-tauri/core/src/search.rs`

## 検索の規則

| ID | 要件 |
|---|---|
| REQ-SRC-001 | 検索語と材料の値を同じ規則で正規化して部分一致で比べる: NFKC → 小文字 → 連続する空白を1つ → 前後の空白を除く（全角・半角、大文字・小文字を区別しない） |
| REQ-SRC-002 | 比べる項目は品名・型式・メーカー・備考（数量・単価は対象外）。どれかに含まれれば一致 |
| REQ-SRC-003 | 削除した材料は出さない。無効の材料は「無効も表示」（`includeInactive`）のときだけ出す |
| REQ-SRC-004 | カテゴリを選んだらそのカテゴリだけに絞る |
| REQ-SRC-005 | 並び順はカテゴリの並び順・カテゴリ ID・品名・材料 ID。1回に25件、`offset` から返し、条件に合う総数 `total` も返す |
| REQ-SRC-006 | 応答には、並び順の先頭1,000件のカテゴリ（件数付き）と、カテゴリの総数を含める（旧版との互換のため。画面はカテゴリ候補を `materials:categories` で取る） |
| REQ-SRC-007 | カテゴリ候補（`materials:categories`）は、カテゴリ名を同じ規則で部分一致し、並び順で100件ずつ返す。件数は `includeInactive` の条件で数えた、削除していない材料の数。絞り込む前のカテゴリの総数 `categoryTotal` と材料の総数 `materialCount` も返す |
| REQ-SRC-008 | 検索語は256文字まで。画面は、変換中に欄の文字が256文字を超えても、送る検索語を先頭の256文字に切る（欄の表示は切らない） |
| REQ-SRC-009 | 画面は、入力から180ミリ秒待ってから検索し、新しい入力があれば古い応答を捨てる。カテゴリ・ページの切り替えはすぐに検索する |
| REQ-SRC-010 | 日本語の変換中も、確定を待たずに入力中の文字で検索する。確定した文字が今の検索語と同じなら検索し直さない |

## 材料検索パレット

Ctrl+F・ヘッダーの「材料を検索…」・明細の「材料を選んでまとめて追加」で開くモーダル。

| ID | 要件 |
|---|---|
| REQ-SRC-101 | 有効な材料だけを検索する（「無効も表示」はない） |
| REQ-SRC-102 | ↑↓で行を移り、Enter・クリックで選択／解除する。選んだ材料は、検索語・カテゴリ・ページを変えても、パレットを閉じても残る |
| REQ-SRC-103 | 「N件を明細に追加」（Ctrl+Enter）で、選んだ順に開いている請求書の明細の末尾へ追加する。請求書を開いていなければ新しい請求書を作って追加する |
| REQ-SRC-104 | 選べる数は、明細の上限500行から今の明細の行数を引いた数まで。超えて選べない。既に超えていれば追加できず、減らす数を示す |
| REQ-SRC-105 | 追加できた材料は選択から外す。途中で失敗したら、そこまでの分だけ明細に入れ、残りは選んだまま残して理由と件数を示す |
| REQ-SRC-106 | 明細に既にある材料には「明細にあり」を付ける（追加は止めない） |
| REQ-SRC-107 | 材料を削除したら、その材料を選択から外す |
| REQ-SRC-108 | Esc・背景のクリックで閉じ、開く前のフォーカスへ戻す |

## 明細最終行の検索欄

| ID | 要件 |
|---|---|
| REQ-SRC-201 | 検索語（前後の空白を除く）があるときだけ、候補を上位8件まで出す（総数も示す） |
| REQ-SRC-202 | ↑↓で候補を選び、Enter・クリックで1件追加する。「空の明細を追加」で材料なしの明細を追加する |
| REQ-SRC-203 | 変換中の Enter・↑↓は IME に任せる。変換中に候補・ボタンを押したときは、先に変換を確定してから追加する |
| REQ-SRC-204 | 明細が500行に達したら欄を無効にし「明細は500行までです。」を示す |

## 明細への追加（`documents:add-line`）

| ID | 要件 |
|---|---|
| REQ-SRC-301 | 開いている編集セッションに対して1件ずつ追加する。材料の品名・型式・メーカー・数量・備考を写し、チェックは未選択（`unknown`・`unresolved`・`provisional-v1`）、出典（材料 ID と最後に反映した原記録）を記録する |
| REQ-SRC-302 | 材料が見つからない・無効・削除済みなら「材料が見つからないか無効です。再検索してください。」（`NOT_FOUND`） |
| REQ-SRC-303 | 1つの編集セッションで追加できるのは2,000行まで（「この編集セッションの追加上限です。保存して開き直してください。」） |
| REQ-SRC-304 | 追加した明細の数量の欄へフォーカスを移し、「「品名 型式」を明細Nに追加しました」（複数なら「N件の材料を明細A～Bに追加しました」）と知らせる |

## 0件のときの案内

| 状況 | 文言 |
|---|---|
| 検索語かカテゴリで絞っている | 該当する材料はありません。キーワードやカテゴリを変更してください。 |
| パレット・絞っていない | 検索できる材料がありません。「材料」タブの「Excelから取込」または「手動で追加」から登録してください。 |
| 材料台帳・無効も表示 | 材料はまだ登録されていません。「Excelから取込」または「手動で追加」から登録してください。 |
| 材料台帳・無効を隠している | 表示できる材料はありません。「Excelから取込」または「手動で追加」から登録してください（無効にした材料は「無効も表示」で表示できます）。 |

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-SRC-001 | 品名「ＡＢＣ　ボルト」の材料 | 「abc ボルト」で検索 | 見つかる |
| AC-SRC-002 | 無効の材料・削除した材料 | パレットで検索 | どちらも出ない |
| AC-SRC-003 | パレットで2件選ぶ | 検索語を変えて1件選び、Ctrl+Enter | 3件が選んだ順に明細の末尾に入り、選択が空になる |
| AC-SRC-004 | 明細が499行 | パレットで2件目を選ぼうとする | 選べず「明細は500行までのため、これ以上は選べません。」 |
| AC-SRC-005 | カテゴリが150件 | カテゴリ候補を見る | 検索欄と「次の100件」が出て、2ページ目の101〜150件目を選べる。ページを変えても選んだカテゴリは残る |
| AC-SRC-006（変換中） | パレットの検索欄で変換中（候補は変換中の文字で出ている） | Enter を押す | Enter は変換の確定に使われ、選択は変わらない |
| AC-SRC-007 | 3件の追加の2件目で失敗する | パレットから追加 | 1件だけ明細に入り、2件目以降は選んだまま残り、理由と「選んだ3件のうち1件を追加しました」が出る |

## 未確定・既知の問題

- `audit/` の E-02（請求書一覧に戻った後のパレットからの追加が、前に開いた請求書へ入る）・E-03（別の請求書で選んだまま追加しなかった材料が持ち越される）は未対応。推奨は「編集画面以外から追加したら新しい請求書にする」（未決定）。
- E-07（検索欄から Tab で「空の明細を追加」に届かない）は未対応。
- 材料の `search_text` 列は保存しているが検索に使っていない（[09-tech-debt.md](../09-tech-debt.md) の TD-16）。
