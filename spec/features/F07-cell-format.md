# F07 セルの書式と、書式の元に戻す・やり直し

Excel の［ホーム］タブと同じ要領で、帳票の入力欄のセルに書式を付ける。書式はプレビュー・Excel出力・PDF・印刷に同じく反映する。

- 画面: `FormatBar.tsx`（ツールバー）、`SheetPreview.tsx`（セルの選択・ショートカット）、`useFormatHistory.ts`・`format-history.ts`（履歴）
- 定義: `src/shared/cell-format.ts` ⇔ `src-tauri/core/src/format.rs`（同じ定義。[05-sheet-layout.md](../05-sheet-layout.md)）
- 保存: `documents:save` の `draft.formats`（帳票上部）と `lines[].formats`（明細）。DB では `documents.header` の JSON（[04-data-model.md](../04-data-model.md)）

## 書式の項目

| 項目 | 値 | 既定 |
|---|---|---|
| 横位置 `horizontal` | `left`・`center`・`right` | 帳票の既定（文字のあるセルは中央揃え） |
| 縦位置 `vertical` | `top`・`center`（指定なしは下揃え） | 下揃え |
| 太字・斜体・下線 `bold`・`italic`・`underline` | `true` だけを持つ（指定なしが「なし」） | なし |
| 文字の大きさ `size` | 8・9・10・11・12・14・16（pt） | 帳票の既定（11pt、チェック記号は9pt） |
| 文字の色 `color`・塗りつぶし `fill` | 決まった18色（`RRGGBB`。白・淡い灰色・灰色・淡い黄・淡いオレンジ・淡い緑・淡い青・淡い紫と、Excel の「標準の色」10色） | 自動（黒）・塗りつぶしなし |

## 要件

| ID | 要件 |
|---|---|
| REQ-FMT-001 | 書式を付けられるのは入力欄のセルだけ: 帳票上部の5欄と、明細のある行（1〜47行目）のチェック・品名・型式・メーカー・数量・備考。見出し・凡例・空き行・G 列には付かない |
| REQ-FMT-002 | セルはクリック・ドラッグ・Shift+クリック・列や行の見出し・左上の角（すべて）で範囲を選ぶ。範囲の中の入力欄のセルすべてに同じ変更を付ける。ツールバーは、アクティブなセル（入力欄でなければ範囲の最初の入力欄）の今の見た目を示す |
| REQ-FMT-003 | 書式は帳票の既定との差分だけを保存する（既定と同じ横位置・文字の大きさは保存しない）。すべて既定に戻ったセルは書式を持たない。書式のない請求書は、書式を足す前と同じ JSON で保存する |
| REQ-FMT-004 | 明細の書式は明細の ID に付ける。並べ替え・削除・複製で明細と一緒に動く |
| REQ-FMT-005 | 「書式をクリア」で、選んだセルを帳票の既定に戻す |
| REQ-FMT-006 | Ctrl+B・Ctrl+I・Ctrl+U は、編集画面のどこにフォーカスがあっても、選んでいるセルの太字・斜体・下線を切り替える（変換中・処理中は何もしない） |
| REQ-FMT-007 | ツールバーのボタンを押しても、入力欄のフォーカスを動かさない |
| REQ-FMT-008 | 本体は書式の値を検査する（未知のキー・一覧にない色・大きさは入力エラー）。保存した書式で読めないものは無視して請求書を開く |
| REQ-FMT-009 | Excel出力では、書式を付けたセルの組合せ（既定の書式と書式）ごとに `cellXfs` を既定の17個の後ろへ足し、その組合せを `styles.xml` の XML コメントに記録する。既存ファイルへの上書きの前に、記録から作り直して一致するかで、このアプリの出力かを確かめる |
| REQ-FMT-010 | 印刷・PDF の HTML は、書式があるときだけ書式用の固定のクラスを足したスタイルと、そのハッシュの CSP を使う |

## 元に戻す・やり直し

| ID | 要件 |
|---|---|
| REQ-FMT-101 | 書式の変更1回（ボタン1回・ショートカット1回）を1段とし、100段まで元に戻せる。新しく書式を変えると、やり直しの履歴は消える |
| REQ-FMT-102 | 履歴は請求書を開いている間だけ持つ（開き直すと消える） |
| REQ-FMT-103 | ツールバーの「書式を元に戻す」「書式をやり直す」は常に書式だけを戻す・やり直す |
| REQ-FMT-104 | Ctrl+Z・Ctrl+Y（Ctrl+Shift+Z）は、文字の入力欄で押したときは、その欄の文字の入力と書式の変更のうち新しい方から戻す（文字は入力欄の標準の取り消しに任せる）。入力欄の外では書式を戻す・やり直す。明細最終行の検索欄では書式を扱わない |
| REQ-FMT-105 | 文字を入力すると、書式のやり直しの履歴は消える。「入力欄に色を付ける」などの表示の切り替え・チェックボックスでは履歴は変わらない（文字の入力として数えるのは、帳票の文字の入力欄だけ） |
| REQ-FMT-106 | 削除した明細だけに関わる段は飛ばす |
| REQ-FMT-107 | 明細の追加・削除・並べ替えは元に戻せない（履歴に入れない） |

### 状態と遷移（Ctrl+Z を文字の入力欄で押したとき）

| 欄の文字の最後の入力 | 書式の最後の変更 | 戻すもの |
|---|---|---|
| ない | ある | 書式 |
| ある（書式より新しい） | ある | 文字（標準の取り消し）。標準の取り消しで戻せる文字がなかったら、その欄の記録を捨て、次の Ctrl+Z で書式へ進む |
| ある（書式より古い） | ある | 書式 |
| ある | ない | 文字（標準の取り消し） |

## 受け入れ基準

| ID | 前提 | 操作 | 結果 |
|---|---|---|---|
| AC-FMT-001 | 明細2行 | 品名の列の見出しを押して太字にする | 明細のある2行の品名だけが太字になり、空き行・見出しは変わらない |
| AC-FMT-002 | 明細1の品名が太字 | 明細1と2を並べ替える | 太字は明細と一緒に2行目へ動く |
| AC-FMT-003 | 書式を付けた請求書 | Excel出力・PDF保存 | 同じ書式で出る。同じファイルへの上書きも受け付ける |
| AC-FMT-004 | 品名の欄で「書式を変える→文字を打つ→書式を変える」 | その欄で Ctrl+Z を2回 | 2回目の書式、文字の順に戻る |
| AC-FMT-005 | 書式を元に戻した | 文字を入力する | 書式のやり直しができなくなる |
| AC-FMT-006（想定外の操作） | 「入力欄に色を付ける」を切り替える | Ctrl+Y | 書式のやり直しができる（履歴は消えない） |

## 対象外

セルの結合・罫線・折り返し・縮小して全体を表示・フォントの種類・数値の表示形式・条件付き書式。キーボードだけでの範囲選択。

## 未確定・既知の問題

`audit/` の S-01（Ctrl+Z の順番がブラウザのページ全体の取り消しの履歴と合わない。推奨は「文字と書式を区別せず最後の操作から戻す」で未決定）、S-02（書式を付けた請求書を旧 Electron 版で保存できない）、S-03〜S-08（範囲の選び直し・変換中のツールバー・色の一覧のフォーカスなど）。
